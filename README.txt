LOGESH'S BIRTHDAY SURPRISE WEBSITE
==================================

1) Open index.html in Chrome or Edge to preview the website on your PC.
2) When your birthday video is ready:
   - Copy the video into the same folder as index.html.
   - Rename it to: birthday-video.mp4
   - In index.html, replace the video placeholder area with:
       <video controls playsinline>
         <source src="birthday-video.mp4" type="video/mp4">
       </video>
   (The current "Add your birthday video" button is only a local preview. It does not upload a video to the internet.)
3) To publish a permanent shareable link:
   - Create/sign in to GitHub.
   - Create a new public repository, for example: logesh-birthday.
   - Upload index.html and birthday-video.mp4 (if ready).
   - In repository Settings > Pages, choose "Deploy from a branch", select "main" and "/ (root)", then Save.
   - GitHub will provide a public URL. Share that URL with Logesh.
   Keep the repository public for a free GitHub Pages site.

IMPORTANT:
- The website files are the starting point; no public URL is created yet.
- A local video preview selected with the button is visible only on your PC.
- For the shared website, the video must be uploaded alongside the HTML file (or hosted elsewhere with a public video URL).
